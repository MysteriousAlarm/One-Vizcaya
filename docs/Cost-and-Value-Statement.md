# One Vizcaya — Cost & Value Statement
### Prepared for the Provincial Government of Nueva Vizcaya
#### Development value, service engagement, and infrastructure cost — reframed for procurement clarity

---

> **The one-sentence summary:** The Provincial Government is **not** being asked to pay for development. The system is already built. What is proposed is a modest annual **service engagement** for maintenance, security, and support — with cloud infrastructure billed at actual cost and no markup.

---

## 1. How to Read This Document

There are three separate numbers in any software engagement, and they are often confused. This document keeps them clearly apart:

| Number | What it is | Who pays it |
| :--- | :--- | :--- |
| **Development value** | The market cost of building the system | **No one — already done at ₱0 to the LGU** |
| **Service fee** | Ongoing maintenance, security, support, improvements | The LGU, annually, if the engagement proceeds |
| **Infrastructure cost** | Cloud hosting and database (Firebase/GCP) | The LGU, at actual cost, no markup |

The most important point: **the development value is a context figure, not a price.** It shows what the province would have paid commercially. It is not something we are invoicing.

---

## 2. Development Value (Provided at ₱0 to the LGU)

One Vizcaya was built by a three-person undergraduate team from Nueva Vizcaya State University as an academic-origin project for their home province. No development hours are billed to the Provincial Government.

For transparency, here is the honest market value of the work already completed, costed at **undergraduate / junior-developer rates** (below professional agency rates), based on realistic hours per component.

### 2.1 Component Breakdown

| Component | Est. Hours | Value @ ₱375/hr |
| :--- | :--- | :--- |
| Flutter Mobile App (citizen-facing) | 455 | ₱170,625 |
| Municipal Web Dashboard | 425 | ₱159,375 |
| Provincial Command Hub | 235 | ₱88,125 |
| Firebase Backend (rules, functions, hardening) | 315 | ₱118,125 |
| Architecture, Design, Documentation & PM | 260 | ₱97,500 |
| **TOTAL** | **~1,690 hrs** | **₱633,750** |

### 2.2 Value Range

Because rate assumptions vary, the honest range of development value is:

| Rate basis | Hours | Total value |
| :--- | :--- | :--- |
| Conservative (₱350/hr) | 1,700 | ₱595,000 |
| Midpoint (₱375/hr) | 1,700 | ₱637,500 |
| Upper undergrad (₱400/hr) | 1,700 | ₱680,000 |

> **Development value provided to the Provincial Government: approximately ₱595,000 – ₱680,000, delivered at ₱0 development cost.** This is the value the province gains access to at no capital expense.

## 3. Commercial Comparison (Context Only)

To put the value in perspective — this is **not** our ask, only a market reference:

| Procurement route | Typical cost for equivalent scope |
| :--- | :--- |
| Undergraduate team (this project) | ~₱640,000 value, provided at ₱0 dev cost |
| Philippine software agency quote | ₱1.2M – ₱2.5M |
| Government IT project via full BAC procurement | ₱3M – ₱5M+ |

The gap exists because agencies and full procurement add overhead, profit margin, account management, consultancy fees, and procurement costs. The province is receiving a system of real commercial value without any of that markup.

## 4. The Actual Ask — Annual Service Engagement

This is the **only** figure the Provincial Government is asked to fund. It covers keeping the system secure, working, updated, and supported after deployment.

| Service | Hours / year | Annual cost |
| :--- | :--- | :--- |
| Security monitoring & rule updates | 120 | ₱60,000 |
| Feature updates per LGU / committee requests | 200 | ₱100,000 |
| Bug fixes & compatibility updates | 80 | ₱40,000 |
| Infrastructure management & monitoring | 60 | ₱30,000 |
| Support & training for new LGU staff | 40 | ₱20,000 |
| **TOTAL** | **500 hrs** | **₱250,000 / year** |

### 4.1 Service Fee Range

| Tier | Monthly | Annual |
| :--- | :--- | :--- |
| Lower bound | ₱15,000 | ₱180,000 |
| Recommended | ₱20,000 | ₱240,000 |
| Upper bound | ₱25,000 | ₱300,000 |

> **The recommended service engagement is ₱15,000 – ₱25,000 per month** for a three-person team maintaining and improving a provincial-scale civic and disaster-response platform. This is deliberately lean and well below commercial support rates.

## 5. Infrastructure Cost (Actual Cost, No Markup)

Cloud infrastructure (Firebase Blaze on Google Cloud) is billed to the LGU at **exact cost with zero markup**. Cost is driven by activity, not population.

| Scale | Active reporters / mo | Est. infra cost / month |
| :--- | :--- | :--- |
| 1 Municipality (pilot) | ~900 | ≈ ₱0 (within free quotas) |
| 3 Municipalities | ~2,300 | ≈ ₱50 – ₱150 |
| Province-wide (normal) | ~5,300 | ≈ ₱500 |
| Province-wide (heavy + disaster buffer) | ~15,900 | ≈ ₱3,000 – ₱4,500 |

Even province-wide with backups and standard support, total infrastructure stays **well under ₱10,000 / month.**

---

## 6. Total Cost of Ownership Summary

What the Provincial Government actually pays, in plain terms:

| Item | Cost to LGU |
| :--- | :--- |
| **Development** | **₱0** (already built, academic-origin) |
| **Pilot period (3 months, 1 municipality)** | **₱0** (infrastructure within free quotas) |
| **Service fee (post-pilot, if it proceeds)** | ₱15,000 – ₱25,000 / month |
| **Infrastructure (post-pilot)** | Actual cost, ~₱500 – ₱5,000 / month at province scale |

> **Bottom line: a system worth ~₱640,000 to build, and ₱3M–₱5M to procure commercially, is provided with ₱0 development cost and a lean monthly service fee — only if the pilot succeeds and the province chooses to proceed.**

---

## 7. Why This Structure Is Procurement-Friendly

- **No large capital expenditure** for the BAC or COA to justify — there is no lump-sum development invoice.
- **Predictable operating cost** — a modest monthly service fee fits an ordinary budget line rather than a major appropriation.
- **Transparent infrastructure billing** — actual cost, no hidden markup.
- **Clear value-for-money** — a documented commercial equivalent of ₱3M–₱5M delivered for a fraction of that per year.
- **Risk-free evaluation** — the pilot is free; the province commits to nothing until it sees real results.
